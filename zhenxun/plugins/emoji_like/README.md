# 贴表情

回复一条消息后发送单个 emoji，机器人会调用 NapCat / OneBot V11 扩展接口给被回复消息贴表情。

## 使用方式

- 回复消息后发送 `贴㊗️`
- 回复消息后发送 `㊗️`
- 回复消息后发送 `贴👍`
- 回复消息后发送 `贴✨`

插件会把用户发送的单个 emoji 转成对应 Unicode 码点的十进制字符串作为 `emoji_id`，也兼容 `贴<emoji>` 的写法，不维护中文别名或静态表。

## 依赖与限制

- 当前实现面向 OneBot V11 / NapCat。
- 实际调用接口为 `set_msg_emoji_like`，参数为目标消息 `message_id` 和 QQ 表情 `emoji_id`。
- 仅支持归一化后为单个 Unicode 符号码位的 emoji。
- 不支持肤色、国旗、家庭、键帽等组合 emoji；不支持时会静默跳过。
- 不支持取消贴表情；如果协议端没有实现该扩展接口，也会静默跳过。
